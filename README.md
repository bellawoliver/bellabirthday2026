# bellabirthday2026

A simple static birthday wishlist website.

## View locally

Open `index.html` in a browser.

## Deploy with GitHub Pages

This repo includes a GitHub Actions workflow that deploys the static site to
GitHub Pages whenever changes are pushed to `main`.

1. Commit and push these files to GitHub.
2. Open the repository on GitHub:
   `https://github.com/bellawoliver/bellabirthday2026`
3. Go to **Settings** > **Pages**.
4. Under **Build and deployment**, set **Source** to **GitHub Actions**.
5. Push to `main`, or run the **Deploy static site to GitHub Pages** workflow
   manually from the **Actions** tab.

After the workflow succeeds, the site should be available at:

`https://bellawoliver.github.io/bellabirthday2026/`
